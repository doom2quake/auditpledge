AuditPledge · MCP tool provenance for Compound agents

A Compound agent is as trustworthy as the tools it can call.

AuditPledge inventories the MCP tools a Compound-facing agent can call, verifies their provenance and capability, and prices the residual risk in position terms. One unsigned, transaction-signing tool from an unknown publisher is one prompt injection away from moving your collateral. It names that tool, and puts a dollar figure on it.

How to read this

Scan supply chain
Replays the recorded run step by step: each MCP tool is inventoried, risk-scored, then priced. No network, no key.
Critical (glows red)
Unsigned, RCE- or signer-capable, untrusted publisher. This is the named MCP-to-signer path into a Compound position.
Underwriter
Expected annual loss and the loaded premium a risk owner, or their insurer, can act on.
Activity log
The audit trace as it was recorded: one line per stage, with the stage's own result and its measured wall-clock time.
Artifacts
audit-report is the exact stdout of the recorded run. underwriter-quote is derived from the same numbers. Copy or download either.
Replay
Resets and re-runs the demo. Keyboard: Tab to a control, Enter or Space to activate.
